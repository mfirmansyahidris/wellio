# Wellio release artwork

## Launcher icon

- `wellio-launcher-source.png`: original generated source artwork.
- `wellio-play-store-icon-512.png`: 512 × 512 opaque PNG for the Google Play listing.
- Android density, adaptive, and monochrome resources are stored under `app/src/main/res/`.

The icon uses a centered abstract sprout to represent daily growth, movement, and nourishment. Its forest green, cream, lime, and peach palette matches the application interface.

## Generation record

The source artwork was created with the built-in OpenAI image generation tool using a logo-brand prompt. The prompt requested a minimal Android launcher icon with two rounded leaves and an upward sprout, a deep forest green background, cream and lime foreground shapes, a small peach accent, no text, and all essential artwork inside the adaptive icon safe zone.

Before production release, review the icon in Google Play Console previews and on representative Android launchers using circle, squircle, rounded-square, and themed monochrome masks.
